周度数据更新工具 · 使用说明
================================

一、用 Docker 打开网页（推荐）

1. 安装并启动 Docker Desktop，等待状态为 Running。
2. 在本目录打开终端，执行：

   docker compose up --build

3. 浏览器访问：http://127.0.0.1:8765/
4. 周度更新：上传源文件（文件名含 截止YYYYMMDD）和上周分层表，点开始更新，完成后下载产出文件。
5. 考核拆分：上传汇总表&明细，点开始拆分，完成后下载 zip（内含每位理财师一份 Excel）。

样例数据在「样例数据」文件夹中。

二、不用 Docker（需已安装 Python 3.8+）

   pip install -r requirements-web.txt
   python 网页服务.py

然后同样访问 http://127.0.0.1:8765/

三、桌面窗口

   python 周度数据更新工具.py

四、局域网给同事打开

本机用 Docker 或设置 ZHOUDU_BIND=0.0.0.0 后启动，同事访问：
http://本机局域网IP:8765/
需放行防火墙 TCP 8765。本工具无登录，请仅在内网使用。

详细业务说明见「交接文档_周度数据更新工具」。
